# 구슬 레이스 추첨기

이름을 넣고 구슬을 굴려 결승선 통과 순서로 **전체 등수**를 매기는 추첨기입니다.
광고와 트래킹이 없습니다.

**바로 쓰기 →** https://elandonlinemuseum-sketch.github.io/marble-race/

## 기능

- 참가자 최대 200명 (기본 100명 예시 포함), `이름*3` 복수 / `이름/5` 스킬 가중치
- 코스 5종 + 랜덤 — 바람개비 · 핀밭 · 시소 · 범퍼 · 회전판 · 물레방아 · 웅덩이
- **웅덩이**가 결승 직전에 무리를 모아 판을 뒤집고, 폭 전체를 쓰는 마무리 주로에서 접전이 납니다
- 당첨 기준: 전체 순위 / 1등 / N등 / N~M등 / 꼴찌
- 결과 **엑셀(.xlsx) 내려받기**, 순위 복사(탭 구분)
- 선두 클로즈업 카메라, 실시간 등수 표시, 밝게/어둡게

## 구조

- `index.html` — 단독 실행 파일. 더블클릭하면 그대로 열립니다
- `app.html` — 소스 조각 (아티팩트 배포용)
- `build.py` — `app.html` → `index.html` 생성

물리는 [Matter.js](https://brm.io/matter-js/), 엑셀은 [SheetJS](https://sheetjs.com/)를 CDN에서 불러옵니다.
그 외 렌더링·코스·UI는 직접 작성했습니다.
